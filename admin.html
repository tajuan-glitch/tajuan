🔑 เข้าสู่ระบบผู้ดูแล

ใส่โทเค็น GitHub ครั้งเดียว ระบบจะจำไว้ในเครื่องนี้ได้ 30 วัน โทเค็นถูกส่งไปที่ GitHub เท่านั้น ใครไม่มีโทเค็นก็โพสต์ไม่ได้

ที่เก็บเว็บ (ปกติไม่ต้องแก้)
วิธีสร้างโทเค็น

GitHub → รูปโปรไฟล์ → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
เลือก Only select repositories → repo เว็บนี้ · Permissions → Contents = Read and write · ตั้งวันหมดอายุ 1 ปี แล้วคัดลอกมาวาง

จัดการเว็บตาจวนบ้านเรา

ดูเว็บ

วางลิงก์ได้เลย กดเปิดได้ · ลิงก์ YouTube ไว้บรรทัดเดียว จะเล่นในหน้าเว็บ · ตั้งชื่อปุ่มได้แบบ [อ่านต่อ](https://...)

ระบบย่อรูปให้อัตโนมัติ และสร้างรูปเล็กสำหรับหน้าแรก แตะรูปในเว็บเพื่อดูภาพใหญ่
